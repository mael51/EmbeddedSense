# Politique de sécurité

## Signaler une vulnérabilité

Si tu découvres une faille de sécurité, ne l'ouvre pas comme une issue publique. Envoie un message privé au mainteneur du projet pour en discuter avant publication.

## Versions supportées

| Version | Support |
|---------|---------|
| v1.0.x  | Oui     |
| < v1.0  | Non     |

## Ce qui est hors scope

Ce projet est éducatif. Les capteurs et la communication série sont simulés. Aucune donnée sensible n'est traitée.
